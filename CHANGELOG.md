# Changelog

All notable changes to DEVTREE are documented here.

## 0.1.0-alpha.1 — 2026-08-29

- GitHub OAuth and encrypted server-side sessions.
- Evidence V2 scoring with commit-pinned repository and file citations.
- Local Ollama and account-level OpenAI-compatible AI review settings.
- English and Chinese interfaces.
- Fog-of-war skill graph and inspectable evidence drawer.
- Persistent Quests with signed, idempotent GitHub push verification and XP rewards.
- Private-by-default public Developer Passports.
- Career Boss role/JD gap analysis and 4/8/12-week roadmaps.
- PostgreSQL, Redis, Docker Compose, strict TypeScript, and CI verification.

This is an alpha release. Scoring rules and database schemas may change before 1.0.
